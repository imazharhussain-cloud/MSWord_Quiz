# MSWord_Quiz
MS Word quiz for student age 10-17
Microsoft Word Basic Quiz (Urdu) | مائیکروسافٹ ورڈ کوئز

An interactive, responsive, web-based quiz application designed for 10–15 year-old students
who have completed a Basic Microsoft Word course. The entire interface and questions are 
presented in Urdu, optimized for both desktop and mobile screens.
